## 9 Repository and delivery

The client-designated repository holds the ORCE flows and custom nodes, the UI, Helm charts, the profile with schema, the fixtures and discovery reference vectors, the unit tests and the documentation (NFR-CFG-003). Delivered with the source: interface description with example messages (FR-IF-001), code and event list (FR-IF-002), README, runbook and credential provisioning instructions (NFR-DEL001). The demonstrated release is identified by its repository tag (NFR-CFG-001).
